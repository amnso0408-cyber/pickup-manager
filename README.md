# 粗大回収管理アプリ

## アプリの概要
営業が登録した粗大ごみの回収依頼を、ドライバー部門が回収日時とドライバーを割り当てて管理する、社内向けの回収依頼管理アプリです。依頼の登録・更新・削除はメールで全員に通知されます。

## なぜこれを作ったか
営業として働く中で、複数の仕事を並行して進めていると、人間である以上、どうしても連絡ミスや対応の忘れが起きてしまうと感じていました。回収の依頼は、営業からドライバー部門へ引き継がれ、日程の調整も必要になるため、連絡の行き違いが起きやすい業務です。
そこで、依頼の状況をひと目で確認できる一覧と、登録・更新・削除のたびに全員へ届くメール通知で、連絡ミスや確認漏れを少しでも減らせるアプリを作りました。

## 機能
- ユーザー認証(Devise)、ゲストログイン(営業・ドライバー部門)
- 回収依頼の登録・編集・削除
- ロールごとの権限管理(営業 / ドライバー部門)
- 回収日の入力でステータスを自動で「確定」に変更
- 一覧の検索(キーワード・ステータス・回収日の期間)
- メール通知(登録・更新・削除)

## アプリの使い方
ログイン画面の「ゲストログイン」ボタンから、アカウントを作らずに試せます。

### 営業として使う
1. 「営業としてゲストログイン」を押します。
2. 一覧画面の「新規登録」から、会社名・住所・回収品目などを入力して依頼を登録します。ステータスは「確認中」になります。
3. 詳細画面の「編集」から、依頼内容の修正と、ステータスの変更(完了・キャンセル)ができます。
4. 不要になった依頼は、詳細画面の「削除」から削除できます。

### ドライバー部門として使う
1. 「ドライバー部門としてゲストログイン」を押します。
2. 一覧から依頼を選び、詳細画面の「編集」で、回収日とドライバー名を入力します。
3. 回収日を入力すると、ステータスが自動で「確定」になります。

### 権限
- **営業**: 一覧・詳細の閲覧、依頼の登録、依頼内容の編集、ステータスの変更(完了・キャンセル)、依頼の削除
- **ドライバー部門**: 一覧・詳細の閲覧、回収日とドライバー名の入力

## 工夫したところ
### 機能をシンプルに、分かりやすくした
営業とドライバー部門が、迷わず使えることを最優先にしました。一覧では、キーワード・ステータス・回収日で絞り込め、ステータスは色付きのラベルで、ひと目で状況が分かります。

### メール通知で、従来のやり方も取り入れた
依頼の登録・更新・削除のたびに、全員へメールで通知されます。普段から使い慣れているメールも併用することで、新しいアプリを使うときに起きやすい混乱を減らし、確認漏れを防ぐようにしました。

## 技術的なこだわり
### ロールごとの権限を、画面とサーバーの両方で制限した
営業とドライバー部門で、操作できる範囲を分けています。画面では、ロールに応じて、入力できる項目やボタンだけを表示します。ただし、画面で隠すだけでは、URLを直接入力されたときに操作できてしまうため、コントローラ側でも、`before_action` で登録・削除を営業のみに制限し、許可するパラメータもロールごとに切り替えています。
